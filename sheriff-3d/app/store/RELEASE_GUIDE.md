## 5. 프로덕션 신청 직전 체크리스트
| ✅ | 확인 |
|---|---|

| ☐ | 실제 폰에서: 설치 → 튜토리얼 → 한 판 → 저장·이어하기 → 사진 저장 확인 |
| ☐ | 프로덕션 액세스 신청 설문: 테스트에서 받은 의견과 고친 점 적기 |

## 6. 출시 후 할 일
- 오류 기록 보기: Firebase 콘솔 → Firestore → `errors` 컬렉션 (게임 버전·기기 종류·오류 내용). claude.ai 버전은 순위표 문서의 `errs` 칸에 남아요
- 🎬 홍보 영상: `store/promo.mp4`를 YouTube에 올리고(일부 공개 가능) 그 주소를 스토어 등록정보의 「동영상」 칸에 넣기
- 📱 세로 영상: `store/promo-vertical.mp4`(1080×1920, 15초)는 YouTube 쇼츠·인스타 릴스·틱톡용
- 🌐 영어 등록정보: `store/listing_en.md`를 Play Console → 기본 스토어 등록정보 → 번역 추가(영어)에 붙여 넣기
- 첫 주: 리뷰에 답글 달기 · 충돌(ANR/크래시) 보고서 확인 (Play Console → 품질)
- 업데이트할 때마다 `app/android/app/build.gradle`의 versionCode +1, versionName 올리기
- 게임 안 「📰 새 소식」 내용(`NEWS`)을 업데이트 내용으로 바꾸기
- 앱은 5판 이상 즐긴 사람에게 한 번만 별점을 부탁해요 (자동)
