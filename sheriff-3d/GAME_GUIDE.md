## 2. 시작 화면

처음 보는 사람도 헷갈리지 않게 큰 갈래 3개로 정리돼 있습니다.

| 버튼 | 들어 있는 것 |
|---|---|
| ▶ **출발!** | 마지막에 한 모드(와 난이도)로 바로 시작 |
| ⚔️ **싸우기** | 일반 · 무한 변이 · 이번 주 이벤트 · 주간 보스 러시 · 오늘의 규칙, 난이도·역할 고르기, 🗼 보스 탑, 🌟 이달의 보스, 🌙 밤 습격, 💾 이어하기 |
| 🃏 **도전하기** | 📖 이야기 모드 · 🃏 카드 모험 · 🗺 현상금 지도 · 🎯 연습장 |
| 🏇 **놀기** | 🏇 탈것 경주 · 🔔 결투 · 🎣 휴식 놀이 · 👥 함께하기 · 📇 친구 목록 · 🏆 친구 리그 · 🎁 초대하기 · 🐉 친구 레이드 |
| 📅 일지 · 📬 우편함 · 🛒 상점 | 출석·오늘 할 일·도전 / 받은 보상 기록 / 보급품·꾸미기·차고·시즌 패스·사무소 |
| ☰ 더 보기 | 기록·설정·도감·가방 등 |

- **보안관 등급**(🥉 동 → 🥈 은 → 🥇 금 → 💎 다이아 → 👑 전설): 모든 놀이의 기록이 모여 점수가 됩니다.
- **💡 다음 추천**: 처음 몇 판 동안 무엇을 하면 좋을지 알려 줍니다. 그 뒤에는 ⭐ 오늘의 추천이 나옵니다.
- 새 보안관은 레벨이 오르면 기능이 하나씩 열립니다 (결투·카드·지도 Lv2, 무한·경주 Lv3, 규칙·이벤트·시즌 패스 Lv4, 러시·탑 Lv5).

## 3. 조작법

### PC
| 키 | 기능 |
|---|---|
| W A S D / 방향키 | 이동 |
| 마우스 | 시점·조준 (화면 클릭 시 마우스 고정) |

| R | 재장전 |
| 숫자 키 / 마우스 휠 | 무기 교체 |
| Shift | 💨 구르기 (0.4초 무적, 3초마다) · 탈것 위에서는 대시 |
| F / C / Space | 탈것 타기·내리기 / 탈것 바꾸기 / 탈것 기술 |
| T / G | 🪤 곰덫 / 🛢 폭약통 놓기 |

- 버튼: 발사·장전·무기·탈것·회피·기술
- 👆 한 손 모드 (오른손·왼손), 📏 큰 버튼, 📳 진동 세기, 🔋 배터리 절약, 버튼 위치 직접 옮기기

| 16~20 | 화산 광산 | 노을 | 화산 거인 / 선인장 골렘 | 용암 바위 |
| 21~25 | 설원 고개 | 아침 | 성난 황소 / 미친 광부 | 눈보라 |
| 26~30 | 유령 묘지 | 밤 | 유령 총잡이 / 블랙잭 | 묘비·안개 |
| 31~35 | 늪지대 | 아침 | 늪 악어 / 방울뱀 | 천둥 번개 |

| 51~55 | 🏚 유령 마을 (1.8) | 노을 | 유령 총잡이 / 열차 강도단 | 🌾 굴러오는 회전초 |
