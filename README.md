# 틀린그림 찾기 (Day 2 · Game 1)

브라우저에서 바로 실행되는 틀린그림 찾기 웹앱입니다. 설치 없이 `index.html`을 열면 됩니다.

## 기능
- **난이도**: 초급(차이 5개) / 중급(7개) / 고급(9개) — 6·11단계부터 차이가 1개씩 늘어남
- **15단계**: 단계를 깨면 다음 단계가 열리고, 단계별 별(★)과 최고 점수가 저장됨
- **테마 6종 순환**: 🌸봄 마을 → 🏖️여름 해변 → 🍂가을 숲 → 🌙별밤 마을 → ⛄겨울 마을 → 🐠바닷속
- **매번 새 그림**: 장면과 차이가 매번 무작위로 생성됨 (다시 도전해도 새 그림)
- **제한 시간**: 1분 추천 (30초 / 90초 선택 가능), 틀리게 누르면 −3초
- **힌트**: 단계마다 3번 (단축키 H)
- **점수**: 찾은 곳 × 100 + 남은 초 × 10 + 남은 힌트 × 50

## 진행 기록
1. 기본 게임: 난이도 3단계, 1분 타이머, 힌트 3회
2. 그림 품질 향상: 음영·그림자·외곽선·그라데이션 배경(SVG 벡터)
3. 15단계 모드 + 단계별 테마 변경, 가려진 차이 자동 제외
